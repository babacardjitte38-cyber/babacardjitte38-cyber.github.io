Projet scolaireSystèmes · Inventaire

Inventaire automatique du parc avec OCS Inventory et GLPI

Le parc informatique était déjà géré avec GLPI. J'ai déployé OCS Inventory pour recenser automatiquement les ordinateurs, puis je l'ai relié à GLPI : les machines y remontent désormais toutes seules.

  1. Agentsur chaque poste
  2. OCScollecte
  3. Pluginsynchronisation
  4. GLPIparc à jour
  • Déploiement d'OCS Inventory et de sa base MariaDB avec Docker Compose, à côté de GLPI sans le modifier
  • Réseau Docker commun pour relier GLPI à la base OCS
  • Dépannage par les journaux : erreur 500 corrigée (paramètre d'authentification manquant), passage de MySQL 8 à MariaDB
  • Création de la base à partir du schéma fourni par OCS
  • Installation et configuration de l'agent OCS sur un poste Windows
  • Installation du plugin OCS dans GLPI et connexion à la base OCS : l'inventaire remonte automatiquement
  • Rédaction d'un guide d'installation pour reproduire le déploiement en 15 minutes

Terminé : les machines remontent automatiquement dans GLPI
