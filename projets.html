Transcription audio & comptes-rendus par IA

Application web locale qui transcrit un enregistrement audio puis génère automatiquement un compte-rendu, sans envoyer aucune donnée vers le cloud.

  • Backend Python / FastAPI, frontend React / Vite
  • Transcription avec Whisper, rédaction avec Mistral via Ollama (100 % local)
  • Authentification JWT, historique SQLite, exports PDF / DOCX
  • Déploiement complet via Docker Compose : aucune installation technique côté client
  • Python
  • FastAPI
  • React
  • IA
  • Docker
